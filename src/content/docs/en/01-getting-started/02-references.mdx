## What is Nebula?

Nebula is not a closed, hidden integration. It is your own documentation component laboratory. You are free to modify the source code of components, layouts, and the complete design.

### Features

- **Semantic HTML**: Uses `<nav>`, `<aside>`, `<article>`, `<header>`.
- **Full ownership**: The code lives in your `src/` folder.
- **Tailwind CSS v4**: Modern styling without giant files.
- **Zero div soup**: Only the tags you need.

> This is a simple blockquote with some quoted text. It should have a left border and a slightly different background to stand out from the regular content flow.
>
> — Someone Famous

## Código

### Código en línea (CodeInline)

Cuando hablamos de variables, podemos referirnos a `const usuario = "Juan"` o a funciones como `getUserById(id)`. El inline code debe destacar sin romper el flujo del texto.

También se puede usar `npx create-astro@latest` para comandos en línea.

### Bloque de código (Pre)

```javascript
function saludar(nombre) {
  return `Hola, ${nombre}!`;
}

// Ejemplo de uso
const mensaje = saludar('Mundo');
console.log(mensaje);

const funtionWithNameToLargeAndWithALotOfParameters = (parameter1: string, parameter2: string, parameter3: string, parameter4: string) => {
  return "Test"
}
```

```css
.markdown-body {
  max-width: 800px;
  margin: 0 auto;
  padding: 2rem;
}
```

npm install @tailwindcss/typography
npx astro add mdx

When we started building Nebula, we evaluated several static site generators. Here's why we picked Astro.

## Performance

Astro's islands architecture means we ship **zero JavaScript by default**. For a documentation-focused product, this is a perfect fit.

## Developer experience

The component model is intuitive. We can use `.astro` files for static content and add interactivity only where we need it.

## Community

The Astro community is active and helpful. Whenever we got stuck, there was already an answer out there.

We're happy with the choice. The framework gets out of our way and lets us focus on content.
